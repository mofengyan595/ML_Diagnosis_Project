# ML_Diagnosis_Project

本项目为机器学习期末课程项目，主题为 **基于机器学习的糖尿病风险预测问诊系统**。项目通过对用户输入的身体指标进行分析，使用机器学习模型预测糖尿病风险，并通过可交互界面展示预测结果、风险概率和相关说明。
