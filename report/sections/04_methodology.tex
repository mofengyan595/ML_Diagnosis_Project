\section{方法与实验设置}

\subsection{整体流程}

为保证模型比较公平，本文将数据划分、预处理参数估计、模型训练和测试评估分开处理。
原始数据先标记缺乏合理医学含义的 0 值，
再通过分层抽样划分为训练集、验证集和测试集。
中位数填充器、IQR 裁剪边界和标准化器均由训练集确定；
验证集负责模型筛选、超参数调优和分类阈值选择；
方案确定后，再用测试集进行一次独立评估。

\subsection{模型选择}

本文首先使用 Logistic Regression 作为可解释基准模型：
设置 \texttt{class\_weight="balanced"}、最大迭代次数 1000、
随机种子 42，并将其作为后续模型比较的参照。
在此基础上，多模型比较阶段沿用上一节的数据划分和预处理结果。
所有候选模型均只在训练集上拟合，
再分别在验证集和测试集上按同一指标评估，
从而保证不同模型之间以及与 Logistic Regression 基准模型之间的可比性。

除 Logistic Regression 基准模型外，实验纳入 KNN、Decision Tree、
Random Forest、SVM、Gradient Boosting、XGBoost 和 LightGBM。
这些模型覆盖距离方法、线性模型、最大间隔分类器、单树模型和集成学习，
便于在相同预处理流程下比较不同建模假设。

评价时，本文对每个模型都计算 Accuracy、Precision、Recall、F1-score 和 ROC AUC，
并保持验证集与测试集的计算口径一致。
由于糖尿病风险预测属于筛查任务，
漏判高风险样本可能使潜在阳性个体错过进一步检查，
因此模型比较不能只关注 Accuracy，
还应重点观察 Recall 和 F1-score，
并结合 ROC AUC 衡量模型对正负样本的整体排序能力。

\subsection{超参数调优协议}

多模型比较完成后，本文仅依据验证集结果确定调参对象，
避免测试集信息参与模型选择。
SVM 在验证集 Recall 和 F1-score 上表现最好，
Logistic Regression 作为可解释线性基准保留作对照，
因此最终调参阶段聚焦于这两个模型。

调参采用 GridSearchCV，
交叉验证方式为 5 折 StratifiedKFold，
划分时设置 \texttt{shuffle=True} 和随机种子 42，
搜索评分指标为 ROC AUC。
Logistic Regression 的搜索空间包括
$C \in \{0.01,0.1,1,10,100\}$、
\texttt{solver} $\in$ \{\texttt{liblinear}, \texttt{lbfgs}\}、
\texttt{penalty}=\texttt{l2}
以及 \texttt{class\_weight} $\in$ \{None, \texttt{balanced}\}。
SVM 采用 RBF 核，
搜索空间包括
$C \in \{0.1,1,10,100\}$、
\texttt{gamma} $\in$ \{\texttt{scale},0.01,0.1,1\}
以及 \texttt{class\_weight} $\in$ \{None, \texttt{balanced}\}。

得到最优超参数后，本文在验证集上以 0.01 为步长搜索 0.25--0.75
范围内的分类阈值，并以 F1-score、Recall 和 ROC AUC 综合排序。
由于筛查场景更关注减少假阴性，最终阈值选择优先保证较高 Recall。

最终选择的模型为 SVM，
最优参数为 $C=10.0$、\texttt{gamma}=0.01、
\texttt{class\_weight}=None，
验证集上选择的分类阈值为 0.30。
实验过程保留调参记录、最优参数配置和最终模型对象，
以支持模型选择过程的复现。

\subsection{评价指标}

糖尿病预测是类别不平衡二分类问题，
单一 Accuracy 可能掩盖阳性样本漏判。
因此本文纳入 Accuracy、Precision、Recall、F1-score 和 ROC AUC 作为评价指标。
其中 Recall 衡量真实阳性样本被正确识别的比例；
在筛查场景中，假阴性意味着潜在高风险个体被漏掉，
因此 Recall 和 F1-score 比单纯 Accuracy 更需要关注。
ROC AUC 不依赖单一分类阈值，
用于衡量模型对阳性样本和阴性样本的整体区分能力。
