\section{结论、局限性与分工}

\subsection{结论与局限性}

在统一预处理和固定数据划分下，多模型比较结果表明，
SVM 在测试集上的 Recall 和 F1-score 分别达到
0.7778 和 0.6829，均为基础候选模型中的最高值；
Random Forest 的 ROC AUC 达到 0.8275，
体现出较好的概率排序能力。
XGBoost 的 Accuracy 为 0.7468，与 SVM 持平，
但 Recall 和 F1-score 低于 SVM。
Decision Tree 和 Gradient Boosting 在默认参数下表现相对较弱。

上述结果说明，糖尿病风险预测不能只依据 Accuracy 选择模型。
由于漏判高风险样本可能使潜在阳性个体错过进一步检查，
模型选择应综合考虑 Recall、F1-score、ROC AUC 和分类阈值。
基于前序模型比较结果，最终调参阶段选择 SVM 和
Logistic Regression 作为候选模型进行 GridSearchCV 搜索。
最终模型为阈值优化后的 SVM，
最优参数为 $C=10.0$、\texttt{gamma}=0.01、
\texttt{class\_weight}=None，
并在验证集上选择 0.30 作为分类阈值。
该模型在测试集上取得 0.7403 的 Accuracy、
0.5972 的 Precision、0.7963 的 Recall、
0.6825 的 F1-score 和 0.8215 的 ROC AUC。
相较于 Logistic Regression 基准模型，
最终模型将测试集 Recall 从 0.7037 提升到 0.7963，
F1-score 从 0.6441 提升到 0.6825，
同时将假阴性数量由 16 降低到 11。

系统展示方面，本文基于 Gradio 构建了糖尿病风险预测问诊 Demo。
Demo 优先加载最终模型 \texttt{models/best\_model.pkl}，
并复用训练阶段保存的预处理对象完成单样本推理。
系统不仅输出风险概率和低/中/高风险等级，
还增加了输入异常校验、单位与范围提示、关键因素解释和生活/就医建议。
当用户输入明显不合理的医学指标时，
系统会提示“输入异常 / 无法评估”，
避免对无效输入给出误导性风险概率。

本文仍存在若干局限。
首先，Pima 数据集样本量有限，
且样本人群限定为至少 21 岁的 Pima Indian 女性，
模型结论不宜直接推广到其他人群。
其次，数据仅包含 8 个结构化生理指标，
缺少饮食、运动、用药史等更完整的临床信息。
最后，项目模型只能用于课程实验和风险提示，
不能作为医学诊断工具。

后续工作可进一步扩大数据规模，
并引入饮食、运动、用药史、既往检查结果等更丰富的临床变量。
此外，还可使用概率校准、代价敏感学习或更细粒度的阈值策略，
在控制漏判风险的同时平衡 Precision 和 Recall。
对于模型解释，可以进一步引入 SHAP 等个体级解释方法，
使系统能够给出更具体的单样本特征贡献说明。
最后，还应继续完善 Demo 部署和用户测试，
提高系统在课程展示和实际交互中的稳定性。
