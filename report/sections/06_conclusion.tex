\subsection{结论与局限性}

在统一预处理和固定数据划分下，SVM 在基础比较中取得最高的
Recall 和 F1-score；进一步调参后，阈值为 0.30 的 SVM 在测试集上达到
0.7403 Accuracy、0.7963 Recall、0.6825 F1-score 和 0.8215 ROC AUC。
相较 Logistic Regression 基准模型，最终模型将 Recall 从 0.7037
提升到 0.7963，并将假阴性数量由 16 降至 11，说明其更适合课程项目中的
风险筛查目标。

本文还基于 Gradio 构建了问诊 Demo，复用训练阶段保存的预处理对象和最终模型，
输出风险概率、风险等级和简要因素说明，并对明显不合理输入进行拦截。
局限性在于 Pima 数据集样本量较小、人群范围有限，且只包含 8 个结构化指标。
后续可扩大数据来源，引入更多临床变量，并尝试概率校准、代价敏感学习和
SHAP 等个体级解释方法。
