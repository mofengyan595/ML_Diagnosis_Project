\begin{abstract}
面向结构化健康指标的糖尿病风险预测，是健康管理场景中常见的二分类任务。
本文基于 Pima Indians Diabetes Database 构建糖尿病风险预测流程，
将原始数据中缺乏合理医学含义的 0 值作为隐式缺失处理，
并完成异常值裁剪和特征标准化，
并采用分层抽样划分训练集、验证集和测试集。
在固定数据划分和相同预处理流程下，本文以 Logistic Regression 为基准模型，
比较多种传统机器学习与集成学习模型，
再根据验证集结果选择候选模型进行网格搜索、分层交叉验证和分类阈值优化。
实验结果表明，阈值优化后的 SVM 在测试集上的 Accuracy、Precision、
Recall、F1-score 和 ROC AUC 分别为 0.7403、0.5972、0.7963、
0.6825 和 0.8215。
与 Logistic Regression 基准模型相比，最终模型的 Recall 和 F1-score
分别提升 0.0926 和 0.0384，
在当前固定划分下能够识别更多高风险样本，更符合风险筛查中减少漏判的目标。
本文还基于 Gradio 构建了单样本交互式演示系统，
输出风险分数、风险等级、输入异常校验和简要提示。
该风险分数未经概率校准，仅用于风险提示和系统演示，不能替代医学诊断。
\end{abstract}
