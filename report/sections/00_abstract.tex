\begin{abstract}
面向结构化健康指标的糖尿病风险预测是机器学习在健康管理场景中的典型二分类任务。
本文基于 Pima Indians Diabetes Database 构建糖尿病风险预测流程，
对原始数据中的不合理 0 值、隐式缺失、异常值和特征尺度进行统一处理，
并采用分层抽样划分训练集、验证集和测试集。
在统一预处理和固定数据划分下，本文以 Logistic Regression 为基准模型，
比较多种传统机器学习与集成学习模型，
并根据验证集结果选择候选模型进行网格搜索、分层交叉验证和分类阈值优化。
实验结果表明，阈值优化后的 SVM 在测试集上的 Accuracy、Precision、
Recall、F1-score 和 ROC AUC 分别为 0.7403、0.5972、0.7963、
0.6825 和 0.8215。
与 Logistic Regression 基准模型相比，最终模型的 Recall 和 F1-score
分别提升 0.0926 和 0.0384，
能够在当前固定划分下识别更多高风险样本，更符合风险筛查中减少漏判的目标。
本文还基于 Gradio 构建了单样本交互式演示系统，
实现风险分数、风险等级、输入异常校验和简要提示输出。
该风险分数未经概率校准，仅用于风险提示和项目演示，不能替代医学诊断。
\end{abstract}
