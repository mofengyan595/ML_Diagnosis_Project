# 报告写作建议

## 目录说明

报告主文件是 `report/main.tex`，正文按小节拆在 `report/sections/` 下：

- `00_abstract.tex`：摘要和关键词
- `01_introduction.tex`：引言
- `02_related_work.tex`：相关工作
- `03_dataset_preprocessing.tex`：数据集与预处理
- `04_methodology.tex`：方法
- `05_experiments.tex`：实验设置
- `06_results_analysis.tex`：结果与分析
- `07_conclusion.tex`：结论

写作时优先修改对应小节文件，不要把所有内容都堆进 `main.tex`。

## 每节建议

### 摘要

用一段话写清楚：研究问题、数据集、主要方法、最好结果和结论。不要太长，150--250 字左右即可。

### 引言

说明糖尿病早期风险预测的背景和意义，为什么适合使用机器学习。最后用 2--3 点概括本文完成的工作，例如数据预处理、模型比较、Demo 展示。

### 相关工作

简要介绍参考论文中基于 Pima Indians Diabetes 数据集的糖尿病分类研究。重点写已有研究常用的模型、数据划分方式和评价指标，不需要大段翻译论文。

### 数据集与预处理

写清楚数据来源、样本数量、8 个输入特征和 1 个标签。重点说明：

- 不合理 0 值如何处理
- 中位数填充
- IQR 异常值裁剪，边界基于训练集有效观测值计算
- train/validation/test 划分
- 标准化
- 避免数据泄露

这里可以放特征说明表、类别分布图、特征分布图和相关性热力图。

### 方法

先写整体流程：数据集、预处理、划分、模型训练、评估、预测 Demo。然后分别介绍 baseline 和后续对比模型。

如果模型还没全部完成，先保留占位，后面按实际完成情况写 Logistic Regression、KNN、Decision Tree、Random Forest、SVM、XGBoost 或 MLP。

### 实验设置

说明实验环境、统一随机种子、训练/验证/测试划分、是否交叉验证、是否调参，以及 Accuracy、Precision、Recall、F1-score、ROC AUC 的含义。

### 结果与分析

这是报告核心部分。至少放：

- 模型性能对比表
- 混淆矩阵
- ROC 曲线
- 特征重要性图

分析时不要只说“效果好”，要说明哪个指标提升、误判类型、可能原因，以及哪些特征贡献较大。

### 结论

总结最优模型和主要发现。最后写局限性和后续改进，例如数据集规模有限、特征较少、不能替代医学诊断、后续可加入更多模型或 SHAP 解释。

## 图表建议

推荐至少包含以下图表：

- Pipeline 流程图
- 数据集特征说明表
- 模型性能对比表
- 混淆矩阵
- ROC 曲线
- 特征重要性图
- Demo 展示截图

已有图表主要在 `figures/` 目录下。LaTeX 中引用图片时路径可以直接写相对 `report/` 的路径，例如：

```tex
\begin{figure}[t]
  \centering
  \includegraphics[width=\linewidth]{../figures/class_distribution.png}
  \caption{糖尿病风险类别分布}
  \label{fig:class_distribution}
\end{figure}
```

## 编译方式

本报告使用中文和 IEEEtran 模板，请使用 XeLaTeX 编译：

```powershell
cd report
xelatex -interaction=nonstopmode main.tex
```

不要使用 `pdflatex`，否则中文和字体可能出问题。

## 写作注意事项

- 不要删除 `report/IEEEtran.cls`、`report/TUptm.fd` 和 `report/fonts/`，这些用于保证模板和字体稳定。
- 正式写正文时，把 `\placeholder{...}` 替换成普通段落、表格或图片。
- 图表标题要具体，表格列名要包含指标单位或含义。
- 结果数字以当前 CSV 或实际运行结果为准，不要手写旧结果。
- 医疗相关结论要谨慎，报告中应说明系统仅用于课程实验展示，不能替代医生诊断。
